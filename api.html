API Documentation

The planned REST interface for finding and checking addresses programmatically.

Coming soon

These endpoints describe the planned interface. They are not live yet — the app currently runs the finder and checks in your browser.

Base URL

https://api.emailfinder.io/v1

Authentication

Every request carries an API key in the Authorization header.

Authorization: Bearer ef_your_api_key_here
POST /email/find Planned

Return the most likely professional address for a person at a domain.

Request body
{
  "firstName": "John",
  "lastName":  "Smith",
  "company":   "ABC Technologies",
  "domain":    "abctech.com"
}
Response
{
  "email":      "john.smith@abctech.com",
  "confidence": 95,
  "status":     "valid",
  "pattern":    "firstname.lastname"
}
POST /email/verify Planned

Screen a known address and return every signal that was checked.

Request body
{
  "email": "john.smith@abctech.com"
}
Response
{
  "email":       "john.smith@abctech.com",
  "status":      "valid",
  "confidence":  95,
  "syntax":      true,
  "domainShape": true,
  "disposable":  false,
  "role":        false,
  "freeProvider": false
}
POST /email/bulk Planned

Process up to 1,000 contacts in one request.

{
  "contacts": [
    { "firstName": "Alice", "lastName": "Chen",   "domain": "cloudbase.io" },
    { "firstName": "Bob",   "lastName": "Nguyen", "domain": "finstack.com" }
  ]
}
GET /account/credits Planned

Return the credit balance and today's usage for the authenticated account.
